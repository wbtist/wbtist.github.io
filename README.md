## About Me

Hi, and welcome to my portfolio! I'm **Istvan Toth**, a passionate front-end developer currently based in the UK.

I've always believed that a great user experience starts with a solid foundation. That's why my earlier projects—like my interactive browser games (*Pig-Game* and *Hangman*)—were coded entirely from scratch by me. For those, I used a Mobile-First approach with clean Vanilla HTML, CSS, and JavaScript (ES6+), because I love having full control over every single line of my code without relying on heavy frameworks.

However, I'm always looking for the next big thing to level up my workflow. Right now, my absolute focus is on **[Google Antigravity](https://antigravity.google/)**. It's an incredibly powerful tool, and my latest project, the *UK Salary Calculator 2026* (featuring up-to-date UK tax logic), was built entirely using it.

I am continuously expanding my skill set and am always excited to tackle new, innovative challenges. Feel free to look around!

## 📌 About This Repository

Welcome to the source code of my personal GitHub Pages portfolio! This repository serves as the central hub for showcasing my front-end development journey, web applications, and JavaScript browser games.

The site is built with a "Mobile-First" approach, ensuring a seamless and modern user experience across all devices, from desktop monitors to smartphones.

## ✨ Core Features of the Portfolio

* **🌓 Persistent Dark/Light Mode:** Includes a custom theme toggle. The site respects system default preferences and saves user choices to `localStorage` for future visits.
* **📱 Fully Responsive Design:** Utilizes modern CSS media queries to transform data tables into readable, touch-friendly cards on mobile devices.
* **⚡ Zero Dependencies:** Built entirely with Vanilla HTML5, CSS3, and JavaScript (ES6+). No heavy frameworks or external libraries, ensuring lightning-fast load times.
* **🎯 Clean Architecture:** Strict separation of concerns between structure (HTML), styling (CSS), and logic (JS).
